## Characterization

- T-017 established isolated write routing (`RouteIsolatedWrite` / `ExecuteIsolatedWrite`), ensuring that worker tasks generate changes strictly inside isolated scratch environments.
- T-028 established typed coordinator and worker roles (`engineering.RoleCoordinator`, `engineering.RoleWorker`).
- T-029 established machine-observed publication proofs and repository-resident checkpoints.
- Without a fenced Commit Coordinator, there is no centralized authority to validate isolated worker changes, verify candidate diffs, ensure living-plan binding, and apply changes into the primary tree before publication.
- Invariants I-008, I-031, I-032, and I-033 require that only an entity with explicit `RoleCoordinator` authority can apply worker diffs to the working tree and prepare commits, while standard workers (`RoleWorker`) fail closed upon any attempt to coordinate or commit.

## Scope

1. Create `internal/harness/coordinator`:
   - `CommitCoordinator`:
     - Role validation: requires `RoleCoordinator`; rejects `RoleWorker` or unknown roles with `ErrUnauthorizedRole`.
     - Plan revision binding: validates `PlanDigest` freshness against `MASTER_PLAN.md` (`task.CheckPlanDrift`).
     - Candidate verification: validates `CandidateCommit`: `TaskID`, `AttemptID`, `IsolationRoot`, `ModifiedFiles`, `CommitMessage`, `Author`.
     - Path safety checks: ensures modified files do not attempt path traversal outside workspace root or touch forbidden system paths.
     - Diff applicator: safely copies/applies verified modified files from `IsolationRoot` to target workspace.
     - Commit generator: records verified commit details (`CommitResult`: `CommitSHA`, `TreeSHA`, `ModifiedFiles`, `Timestamp`, `PlanDigest`).
2. Tests, benchmarks, and mutation tests:
   - Matrix tests for `CommitCoordinator`: coordinator role success, worker role rejection (`ErrUnauthorizedRole`), plan drift rejection (`ErrStalePlan`), path traversal rejection, missing isolation root rejection.
   - 64-way concurrent commit coordinator evaluation sentinel under `go test -race`.
   - Mutation tests killing defects that bypass coordinator authority checks, path safety, or living plan digests.
   - Permanent CI smoke benchmark: `BenchmarkCommitCoordinatorApply100Operations`.
