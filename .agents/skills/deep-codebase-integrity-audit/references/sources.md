# Authoritative references

This skill is language-agnostic; prefer the repository's language/runtime primary documentation. For Go projects, useful primary references include:

- Go diagnostics / pprof — https://go.dev/doc/diagnostics
- Go race detector — https://go.dev/doc/articles/race_detector
- Go testing and benchmarks — https://pkg.go.dev/testing
- Go compiler diagnostics — https://go.dev/doc/

For databases, queues, caches, and frameworks, use their current official documentation and query/profiling tools rather than generic heuristics.
