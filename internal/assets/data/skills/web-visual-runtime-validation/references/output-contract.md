# Output contract

For a visual-runtime audit or implementation plan, produce:
1. Browser/harness architecture and target states.
2. Progressive validation policy (L0–L4) with escalation budgets.
3. Layout/ARIA evidence schema and deterministic detectors.
4. Screenshot/baseline strategy and determinism controls.
5. Pixel-diff localization strategy.
6. Local VLM provider/routing/prompt/structured-output strategy.
7. VisualEvidencePacket/tool contract to the main agent.
8. Fast inner-loop vs final-regression workflow.
9. Privacy/security policy for screenshots and DOM evidence.
10. Test fixtures for the validator itself and Definition of Done.

For implementation tasks, map changes to actual harness/browser worker/model adapter files and include integration tests. Do not claim a visual pass unless the browser render was actually exercised.
