## Scope

1. Create structural plan audit in `internal/engineering/audit.go`:
   - `AuditPlan(plan string) (PlanAuditReport, error)` and `AuditPlanFile(path string) (PlanAuditReport, error)`:
     - **ID Uniqueness**: Verifies all `T-XXX` and `F-XXX` headings are strictly unique.
     - **Allowed Statuses**: Validates all task statuses against allowed set (`TODO`, `READY`, `IN_PROGRESS`, `BLOCKED`, `DONE`, `REJECTED`, `SUPERSEDED`) and finding statuses against (`OPEN`, `IN_PROGRESS`, `RESOLVED`, `ACCEPTED_LIMITATION`, `REJECTED`).
     - **DAG & Dependency Integrity**: Parses dependency declarations, checks for dangling dependencies (references to undeclared tasks), and validates that the task dependency graph is acyclic.
     - **Finding Severity & Remediation**: Parses finding severities (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFORMATIONAL`), ensures no unmapped Critical/High finding is ignored without an assigned task or explicit accepted limitation.
     - **Checkpoint Recoverability**: Validates the latest Context Compression Checkpoint contains all 15 required fields and references a valid task.
     - **Pre-flight Integrity**: Validates pre-flight directory convention (`.engineering/preflight/T-XXX.md`) and ensures any `IN_PROGRESS` task has a corresponding valid pre-flight marker.
2. Create machine-readable process metrics in `internal/engineering/metrics.go`:
   - `ComputeProcessMetrics(plan string) (ProcessMetrics, error)`:
     - Task counts by status (`Total`, `Done`, `InProgress`, `Ready`, `Todo`, `Blocked`, `Other`).
     - Completion percentage / velocity indicators.
     - Finding counts by severity and status.
     - Digest computation and validation timestamp.
3. Tests and Mutation tests in `internal/engineering/audit_test.go` and `internal/engineering/metrics_test.go`:
   - Validates live `MASTER_PLAN.md` passes full structural audit.
   - Matrix tests for all error conditions (duplicate IDs, invalid status, dangling deps, cycles, unmapped critical findings, missing preflight, malformed checkpoints).
   - Mutation sentinels killing mutants that bypass structural rules.
   - Benchmark test for plan audit and metrics computation.
