- Invariant I-008 ("Single-writer publication: only the coordinator publishes to origin/main; workers never push; force=false is strictly enforced") and Invariant I-033 ("Observed publication proof") require hard enforcement preventing any worker from publishing, prohibiting force-pushes (`force=true` is illegal), verifying clean working trees and living plan freshness, and capturing durable publication proofs.

## Scope

1. Enhance `internal/harness/coordinator`:
   - `ErrForcePushForbidden` error indicating any attempt to use `--force` or `ForcePush=true`.
   - `ErrDirtyWorkingTree` error indicating uncommitted modifications prior to publication.
   - `PublicationRequest`:
     - `Role engineering.Role`, `BranchName string`, `RemoteName string`, `PlanDigest string`, `ForcePush bool`, `CommitSHA string`, `Author string`.
   - `GitClient` interface:
     - `Push(ctx context.Context, remote, branch string, force bool) error`
     - `GetHeadSHA(ctx context.Context) (string, error)`
     - `IsWorkingTreeClean(ctx context.Context) (bool, error)`
   - `Publisher`:
     - `Publish(ctx context.Context, req PublicationRequest, currentPlan []byte) (PublicationResult, error)`
     - Validates `req.Role.AllowsCoordinatorAuthority()` (rejects worker or untyped roles with `ErrUnauthorizedRole`).
     - Enforces `req.ForcePush == false` (rejects with `ErrForcePushForbidden`).
     - Verifies living plan consistency via `task.CheckPlanDrift`.
     - Validates working tree cleanliness (`IsWorkingTreeClean`).
     - Dispatches push to `origin/main` via `GitClient`.
     - Generates structured `PublicationResult` with observed publication metadata.
2. Tests, benchmarks, and mutation tests:
   - Matrix tests: coordinator publication success, worker rejection (`ErrUnauthorizedRole`), force push rejection (`ErrForcePushForbidden`), plan drift rejection (`ErrPlanDrift`), dirty working tree rejection (`ErrDirtyWorkingTree`).
   - 64-way concurrent publication policy evaluator under `go test -race`.
   - Mutation tests killing defects that allow worker pushes, permit force-pushing, or bypass plan drift checks.
   - Permanent CI smoke benchmark: `BenchmarkPublisherEvaluate100Operations`.
