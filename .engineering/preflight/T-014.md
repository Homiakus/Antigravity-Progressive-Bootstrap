## Scope

1. Create automatic read-only routing package `internal/harness/provider/router`:
   - `Router` interface and engine:
     - `Route(ctx context.Context, env harnessmodel.TaskEnvelope, currentPlan []byte) (RouteResult, error)`
     - `Execute(ctx context.Context, route RouteResult, fn ReadOnlyExecutorFunc) (ExecutionResult, error)`
   - Strict read-only invariant (I-032): rejects any `TaskEnvelope` where `Workspace.ReadOnly == false` with `ErrReadOnlyRequired`.
   - Stale plan protection (I-030): validates `CheckPlanDrift(env, currentPlan)` before evaluating routing.
   - Explainable candidate evaluation: bridges `ToSelectorRequest(env)` into `selector.Evaluate(...)`.
   - Atomic assignment & reservation: atomically inserts `ProviderAssignment` (ACTIVE, revision 1, PlanDigest bound) and `ProviderReservation` in SQLite transaction.
   - Lifecycle completion: transitions assignment to COMPLETED and releases reservations upon verified completion.
2. Provide read-only execution abstraction:
   - `ReadOnlyExecutorFunc` and `ExecutionResult` (output artifacts, token metrics, latency, status).
   - Prevents file writes or repo modifications during execution.
3. Tests, benchmarks and mutation testing:
   - Matrix tests for valid read-only routes, write rejection, stale plan rejection, unviable provider fallback.
   - Real SQLite store integration tests.
   - 64-way concurrent router dispatch sentinel.
   - Mutation tests killing mutants that bypass read-only validation, omit plan drift checks, or corrupt reservation amounts.
   - Smoke benchmark for read-only route evaluation and dispatch.
